Trust principleevidence > claims

Context is not memory.

A bounded context packet, durable task state, episodic history and a knowledge graph have different purposes and write permissions. Mixing them creates stale recall and uncontrolled authority.

An architecture is not a benchmark.

Published demonstrations are narrow. The long-form article identifies which behaviors were tested synthetically, which facts came from sanitized task history, and which live experiments remain incomplete.
