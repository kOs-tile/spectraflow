# AGENT AUTOPSY / KAVI PORTFOLIO V3 — Art Direction Contract
**Status:** Experimental preview, not production or independently reviewed design.

## Thesis
> An agent action is a specimen. We peel off generated claims until the only thing left is an independently verifiable receipt.

This is **not** a dashboard, a literary portfolio, a neural-network picture, or a hero-card website. The visual material has a content role: each semi-transparent sheet represents a trust boundary, while the hanging physical receipts represent separate commits or deduplicated attempts. A memory cross-section exposes separate write policies.

We cannot prove no one has ever attempted a similar visual concept. Originality is pursued in the combination of **source-backed action mechanics and optical forensic choreography**, not in a false claim of global novelty.

### Composition / physical vocabulary
- Museum conservation laboratory + forensic examination table, NOT hacker HUD.
- Oxidized teal ink, bone paper, vermilion evidence seals, graphite text, tactile vellum/acetate.
- Real source-backed words/receipts first; large editorial type only when it labels an observable contract.
- Deliberate physical parallax, viewable at every scroll position. No arbitrary floating orbits.
- Responsive physical model: controlled peel on wide screens, readable reduced-motion state for mobile and accessibility.

## Evidence discipline
- [KCC executable demo](https://github.com/kOs-tile/kavi-capability-compiler/blob/main/examples/recruiter_demo.py) is the testable KCC reference for allowed/denied dispatch.
- [SPECTRAFLOW five-minute demo](https://github.com/kOs-tile/spectraflow/blob/main/examples/reliability_interview_demo.py) is separate from a *synthetic* callback/ledger replay and from sanitized historical metadata.
- The synthetic lost-ack comparison has two committed effects (blind) vs one (deduplicated), not externally observed real payment outcomes.
- The 8-record sanitized KAVI fixture counts 2 verified passes, 2 completed-unverified and 4 explicit failures, with no side-effect counts.
- This UI is a *teaching simulation*: button presses are not live tool dispatches and SVG/HTML animations are not instrumentation of actual production tasks.
- The fourteen-layer system [research note](https://github.com/kOs-tile/spectraflow/blob/main/research/ANATOMY_OF_PRODUCTION_AGENTIC_SYSTEMS_2026.md) is a proposed synthesis, not an audited live deployment.

## Release gates
1. Desktop screenshots top, mid-case, ledger, memory, end; inspect actual pixels and vertical hierarchy.
2. Mobile screenshots at 390x844 and 360x740, test no clipped text, controls, navigation or horizontal overflow.
3. Click read/delete, replay retries; keyboard arrow interaction in tablist; reduced motion.
4. Verify link targets and source proof scopes; regressions should fail CI, no silent failures.
5. Review page size, font fallbacks, background noise/readability, and disable motion for prefers-reduced-motion.
6. A human design acceptance gate is required; green structural CI does NOT mean art-direction approval.
7. Old live site and Editorial V2 remain untouched until explicit user approval to promote V3. Higgsfield credits = 0.
